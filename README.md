# Magdalena Wischnewski Portfolio Website

This is a simple academic portfolio website generated from the uploaded CV.

## Files

- `index.html` — main website
- `style.css` — styling
- `script.js` — mobile menu and footer year
- `assets/CV_Wischnewski.pdf` — downloadable CV

## How to use on GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder.
3. Go to Settings → Pages.
4. Under "Build and deployment", choose "Deploy from a branch".
5. Select `main` branch and `/root`.
6. Save. GitHub will give you a public website link.

## Things to edit before publishing

- Replace `your.email@example.com` in `index.html`.
- Add real Google Scholar, ORCID, and university profile links.
- Add a professional photo if desired.
- Review selected publications and update the list as needed.
